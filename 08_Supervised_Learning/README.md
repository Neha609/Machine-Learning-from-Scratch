# 🎯 Supervised Learning

Supervised Learning uses labeled data to learn the relationship between input features and a target variable.

## 📚 Main Categories

### 📈 Regression

Used when the target variable is continuous.

Examples:

- House Price Prediction
- Sales Prediction
- Demand Forecasting

[Explore Regression →](./Regression/)

### 🏷️ Classification

Used when the target variable represents categories or classes.

Examples:

- Customer Churn Prediction
- Fraud Detection
- Loan Default Prediction

[Explore Classification →](./Classification/)

## 🎯 Learning Objective

Understand how supervised Machine Learning algorithms are used for prediction and classification problems.
