## 🎯 Classification Metrics

- Accuracy
- Precision
- Recall
- Specificity

- ROC Curve
- ROC-AUC
- Precision-Recall Curve
- Log Loss

- Cross Validation
- Stratified Cross Validation
- Bias vs Variance

Select and interpret appropriate evaluation metrics based on the Machine Learning problem.
