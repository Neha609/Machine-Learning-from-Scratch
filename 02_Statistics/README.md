# 📊 Statistics for Machine Learning

Statistical concepts required to understand data, identify patterns, and evaluate Machine Learning models.

## 📚 Topics

- Mean, Median and Mode
- Variance
- Standard Deviation
- Percentiles and Quartiles
- Probability Distributions
- Normal Distribution
- Sampling
- Central Limit Theorem
- Confidence Intervals
- Hypothesis Testing
- Correlation
- Covariance

## 🎯 Learning Objective

Understand the statistical foundations used during data analysis, feature exploration, model building, and model evaluation.
